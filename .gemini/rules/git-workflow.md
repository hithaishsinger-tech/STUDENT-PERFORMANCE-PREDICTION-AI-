# Git Auto-Push Rule

Whenever any updates, improvements, bug fixes, or new features are implemented in this repository:
1. Verify the code runs cleanly without errors.
2. Automatically stage all relevant changes (`git add .`).
3. Create a clear, descriptive commit message (`git commit -m "..."`).
4. Push directly to remote repository on branch `main` (`git push origin main`).
5. Surface the commit hash and summary of changes to the user.
